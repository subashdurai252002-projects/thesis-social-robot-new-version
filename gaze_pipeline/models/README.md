# Gaze Pipeline Models

This directory is reserved for model weights used by the gaze pipeline.

Planned models:

- YOLOv8n: person detection
- SAM2 Hiera Tiny: person tracking
- L2CS-Net Gaze360: gaze estimation

The model files are not currently present.

Before adding a model, record:

- Official source
- Filename
- Version
- Licence
- File size
- Checksum
- CPU/GPU compatibility

Large model files should not be committed to Git unless explicitly required.
